# Stockeasy Mobile (Android)

Мобильное приложение Stockeasy для Android на базе **Capacitor**.

## Архитектура
* **Оффлайн-режим (0.1с запуск)**: Все статические файлы интерфейса упаковываются внутрь приложения и открываются локально через Android WebView.
* **Синхронизация с БД**: Все запросы (`/api`) направляются на `https://app.stockeasy.ru`. При потере связи данные сохраняются в IndexedDB и локальную очередь `outbox`. При появлении интернета изменения автоматически синхронизируются с PostgreSQL.
* **Адаптивность**: Поддержка вырезов экранов Android (Safe Area Insets), аппаратной кнопки «Назад», удобные touch-кнопки под пальцы.

## Варианты сборки APK

### 1. Автоматическая сборка в облаке (GitHub Actions)
Вам не нужно устанавливать 15 ГБ Android Studio и SDK на компьютер.
1. Отправьте изменения в ветку `phone`:
   ```bash
   git push origin phone
   ```
2. Откройте репозиторий на GitHub -> вкладка **Actions** -> **Build Android APK**.
3. После завершения скачайте готовый файл **`stockeasy-debug-apk`** и установите на телефон!

---

### 2. Локальная разработка и сборка (на компьютере)
Требуются установленные **Node.js 18+**, **JDK 17** и **Android Studio**.

1. Перейти в каталог `mobile`:
   ```bash
   cd mobile
   npm install
   ```
2. Подготовить и синхронизировать веб-ассеты:
   ```bash
   npm run build
   ```
3. Открыть проект в Android Studio:
   ```bash
   npm run android:open
   ```
   В Android Studio нажмите **Run** (зеленый треугольник) для запуска на подключенном смартфоне или эмуляторе, либо **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**.
